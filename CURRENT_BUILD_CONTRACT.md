# Current Build Contract

## What is being built

A remotely hosted MCP + LLM operating system with permanent occupational agents, guardrails, automated file/photo workflows, remote storage containers, durable living context, permissions/approvals, and a live user-facing HTML/web dashboard/application for Dayna and authorized AI workers.

## Platform corrections

- Production must be off-site/remote.
- No localhost or user's PC as the production server.
- Cloudflare is not part of the current build.
- The prior Well Lived domain requirement is removed.
- Do not inherit prior provider-specific implementation assumptions.
- Use a real web application deployment target. Antigravity/chat is not the production runtime or product UI.

## Definition of built

A component is BUILT only if:
1. code exists;
2. it is integrated into the production path;
3. it executes;
4. its automated tests pass;
5. its observable evidence is recorded.

The project is BUILT only if the deployed end-to-end acceptance tests pass.
