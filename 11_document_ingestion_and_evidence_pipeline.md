# Stage 11 — Document Intake, Catalog, Evidence, and Routing

## Mission
Build the automatic document workflow using the same durable storage/context/workflow system.

## Required work
- Bulk/single document upload through web/API.
- Preserve original and checksum.
- Extract text/content appropriately.
- Classify with provenance/confidence.
- Generate catalog/index records and useful managed names where appropriate without destroying original identity.
- Associate with projects/records/workflows.
- Route to qualified occupational role.
- Preserve evidence links in outputs.
- Allow corrections/supersession without editing the original.

## Acceptance gate
A multi-page test document completes original -> extraction -> classification -> routing -> agent analysis -> evidence-linked output -> dashboard visibility.
