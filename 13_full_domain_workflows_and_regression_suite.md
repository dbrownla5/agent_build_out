# Stage 13 — Connect Real Occupational Workflows and Regression Suite

## Mission
Prove the broader system is more than infrastructure by wiring representative real workflows across the permanent workforce.

## Required work
Implement and test representative complete workflows for:
- career: discovery -> fit -> resume/application -> pipeline;
- correspondence/writing with correct role separation;
- business opportunity -> offer -> pricing -> positioning/campaign as applicable;
- financial record/cash-flow separation;
- resale: intake -> identification -> condition -> comparables -> pricing -> listing -> fulfillment;
- media custody -> derivative preparation -> downstream consumer;
- technical diagnosis -> implementation boundary;
- forensic timeline using evidence without converting allegations/inference into facts.

## Acceptance gate
Each representative workflow must show real role handoffs, evidence, durable state, permissions, and regression tests. No workflow may pass using mocked agent output.
